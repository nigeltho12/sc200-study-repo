# 📘 SC-200 Course Overview

## Exam at a Glance

| Detail | Info |
|--------|------|
| **Exam Name** | Microsoft Security Operations Analyst |
| **Exam Code** | SC-200 |
| **Passing Score** | 700 / 1000 |
| **Format** | ~40–60 questions (MCQ, case studies, drag-drop) |
| **Duration** | 120 minutes |
| **Certification Unlocked** | Microsoft Certified: Security Operations Analyst Associate |

---

## Exam Domain Weights

| Domain | Weight |
|--------|--------|
| Mitigate threats using Microsoft Sentinel | **50–55%** |
| Mitigate threats using Microsoft Defender XDR | **25–30%** |
| Mitigate threats using Microsoft Defender for Cloud | **20–25%** |

> **Key insight:** Sentinel is the majority of this exam. Prioritize it.

---

## Lab Environment

| Component | Details |
|-----------|---------|
| Microsoft 365 License | E5 Developer Tenant (90-day renewable) |
| Azure Subscription | Pay-as-you-go |
| Defender XDR Portal | security.microsoft.com |
| Microsoft Sentinel | Azure Portal → Microsoft Sentinel |
| Endpoint Agent | MDE via Intune MDM enrollment |
| Test Devices | Azure VMs: Windows Server 2022, Ubuntu 22.04 |
| Identity Platform | Azure AD / Entra ID |
| Threat Intel | Microsoft Defender Threat Intelligence (MDTI) |
